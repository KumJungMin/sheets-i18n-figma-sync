번역 데이터 동기화
1.0.4
데이터 소스
Google Sheets URL/ID를 입력하고 새로고침하거나 key 컬럼이 포함된 XLSX 파일을 업로드하세요. 표시된 앞쪽 탭은 최대 3개까지 조회합니다.
이력
저장된 시트는 최신 데이터로 다시 불러오고, 업로드한 XLSX는 저장된 스냅샷을 재사용합니다.
언어
먼저 번역 데이터를 불러오세요.
키 매핑
일반 키는 *title을 그대로 사용합니다. 프레임 키는 PD_JOIN_ServiceGuide 아래의 *title을 PD_JOIN_ServiceGuide.title로 매핑합니다.
적용 범위
현재 페이지 전체에 적용합니다.
